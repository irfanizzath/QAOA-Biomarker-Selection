# Hardware run logs

`seed42.txt`, `seed256.txt`, and `seed1024.txt` contain the recorded QAOA optimization logs for IBM Quantum's `ibm_marrakesh` backend. Each run uses Qiskit 2.6.1 and is summarized in `results/hardware_summary.csv`.

The logs support inspection and reproduction of the reported hardware analysis; new hardware execution requires IBM Quantum access.
